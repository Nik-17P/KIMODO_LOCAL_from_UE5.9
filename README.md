🚀 Как это использовать в будущем (для любого нового проекта):
Создали новый проект UE 5.9.

Зашли в Edit -> Plugins, включили Python Editor Script Plugin, перезапустили UE (нужно только для того, чтобы UE создал папку Intermediate\PipInstall).

Закинули файл Install_Kimodo_All.bat в корень проекта (рядом с .uproject).

Запустили батник.

Дождались надписи «УСТАНОВКА УСПЕШНО ЗАВЕРШЕНА».

Перезапустили UE.

💡 Почему этот скрипт — идеален:
Умное скачивание: Если модели уже есть в D:\Kimodo_Models, snapshot_download проверит их хэш-суммы и мгновенно пропустит скачивание, просто вернув актуальный путь.

Чистый Python из-под капота: Мы генерируем Python-скрипт через PowerShell here-string. Это полностью исключает ошибки с русскими буквами и спецсимволами в BAT-файлах, из-за которых мы страдали ранее.

Иммунитет к обновлениям UE: Мы добавили bInstallDependenciesOnStartup=False. Теперь движок при запуске не будет сходить с ума и пытаться перезаписать наш идеально настроенный PyTorch.

Глубокий патч: Скрипт жестко привязывает локальные пути к коду, сносит __pycache__ и включает HF_HUB_OFFLINE, полностью отрезая плагин от интернета.

Обязательно обратите внимание: В самом начале скрипта (в блоке # ВАЖНО) захардкожен путь к вашему движку: ENGINE_DIR = r"D:\Unreal_Engine\UE_5.9". Если вы установите UE 5.10 в другую папку, просто откройте батник блокнотом и измените эту строчку.

Сохраните этот файл как реликвию. Теперь вы можете разворачивать Kimodo в любом проекте быстрее, чем заваривается кофе!
